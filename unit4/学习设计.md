# Unit 4：伊布的野餐计划

本版设计日期：2026年10月28日。主题：Food with friends；任务：Organise a picnic。沿用 Power Up Level 1 第一版的教学范围，主角按用户要求设为宝可梦伊布（Eevee）。

## 学习路线

所有环节可自由进入。路线勾号表示完成本页练习，不表示通过听写，也不评估孩子的发音或口语水平。15个主关卡外另设补充观察角。

| 环节 | 要学什么 | 怎样互动与完成 |
| --- | --- | --- |
| 1 野餐食物铺 | 第一组10个核心词 | 逐张点读与跟读；点读全部图卡。 |
| 2 水果与餐食 | 第二组9个核心词 | 逐张点读；辨认 fruit、meat、meatballs。 |
| 3 伊布听音寻宝 | 19个核心词的听辨 | 随机顺序听词选图；覆盖全部19词，错误可重听再选。 |
| 4 装进小篮子 | a、an、some | 看图补充6个词组；量词与图片中的数量一致。 |
| 5 我的喜好卡 | I like / I don’t like | 挑选食物与真实喜好，听完整句；试用3种食物。 |
| 6 朋友喜欢什么 | likes / doesn’t like | 对照“角色自己说”和“我们介绍”；完成4题。 |
| 7 问问好朋友 | Do you like…? 和短回答 | 根据给出的喜好卡，替对应角色回答4题。 |
| 8 句子修理站 | 主语与动词变化 | 8题词块选择，重点纠正 doesn’t likes。 |
| 9 我想要一些 | Can I have…? | 明确标注说话者；逐句点读、整段连播；接对请求、递交、感谢3句。 |
| 10 你想来一点吗 | Would you like…? | 接受与礼貌拒绝；对比询问喜好与当下提供；完成6题。 |
| 11 厨房食材架 | 7个补充词和 eggs 复现 | 逐张点读8种材料；与核心听写词分开。 |
| 12 煎蛋卷小厨师 | cut / mix / cook / put / fold | 六步食材状态图、整份食谱点读、乱序排列；实际操作由大人完成。 |
| 13 一起分享野餐 | 理解分享主题 | 六段原创故事，逐段或连播；看完六段并完成3道理解题。 |
| 14 我的野餐计划 | 综合运用 | 选择3—8种食物与饮料，生成请求和邀请卡，可打印作品。 |
| 15 出发前小挑战 | 词汇、量词、语法、交际 | 12道综合题；每题均有解释，不将练习通过自动标成掌握。 |
| 补充：字母 a 观察角 | 已学词中的字母 a | 听 apple、banana、cake 的完整读音，观察字母；不冒充原教材拼读考核。 |

## 核心与补充词

19个核心词：banana、bread、burger / hamburger、cake、chicken、chocolate、lemonade、mango、salad、water、apple、beans、fruit、grapes、juice、meat、meatballs、orange、sausage。

7个补充词：pasta、onions、potatoes、carrots、tomatoes、cheese、rice。eggs 复现 Unit 3，不在 Unit 4 小抽屉重复增加。burger / hamburger 共用一个词条。

Unit 4 小抽屉共26项，按两组核心词及食谱补充分开；每项可点读单词和例句，沿用家庭档案的家长确认与筛选功能。按照网站现行规则，相同英文跨单元共享掌握状态且首次奖励只累计一次；chicken 的词义在本单元清楚标注为“鸡肉”。

## 图片与声音

采用内置生图工具制作9组原始素材，保存完整PNG；页面用独立裁切视窗显示，防止相邻图案串入词卡。素材为野餐主场景、伊布6种动作、核心食物A（10图）、核心食物B（9图）、食材与篮子（9图）、喜好场景（4图）、请求与提供场景（4图）、煎蛋卷状态（6图）、野餐分享结尾。

原六格故事图与带操作动作的食谱图未通过生图服务的输出检查。最终采用单独的分享结尾、现有角色场景和食材状态图完成故事与步骤设计；没有把未成功的图列为交付素材。

2026年10月30日更新：188段英语改为逐条完整合成，保留服务返回的全部录音，不再按语音识别时间裁切单词或句子；在完整录音外增加250毫秒前留白与300毫秒后留白，保护轻辅音和尾音。自然英式语速、Sulafat音色不变；17段中文提示保留，合计205段。每条英文同时检查识别内容、波形首尾余量和实际页面播放。每条音频的实际模型、音色、语言及文件名记录于 audio-manifest.json。单词、必要复数与别名、完整喜好句、请求、邀请、分角色对话、食谱及故事均可点读；不把独立词音频拼成一句话。全部英文均独立合成，不从其他句子或长录音中截取。音频清单与逐句脚本保存在 audio-manifest.json。

角色名由合成语音朗读，不冒充角色原声。故事、例句和插画为家庭学习的原创教学改编，不是剑桥原动画、原故事文本、机构原课件或原录音。伊布和皮卡丘的喜好仅用于本课情境。
