# 玲娜贝儿的农场侦探 · Power Up 1 Unit 3

制作与核查日期：2026 年 10 月 19 日。

## 如何使用

打开 index.html 即可使用本地学习包；在线版可直接在手机或电脑浏览器打开。所有点读音频随包提供，页面不向语音服务提交任何内容。首次播放需要点击图卡或点读按钮。

从农场地图进入任一环节。“图卡点读”控制点选图卡时是否自动朗读，单独的“听一听”按钮始终可用。可以调慢速度或随时停止。建议每次完成少量环节，根据孩子的状态安排，不规定统一学习时长。

点击“我练好了”后标记该环节已练习。这是孩子的练习确认，不代表已经掌握。学习进度、上次学习位置和农场作品保存在当前浏览器；更换设备、清理浏览器数据或切换网页地址后不会自动同步。综合挑战记录每题第一次选择，答错后可以查看解释并重选。

## 本版学习范围

| 环节 | 主要内容 | 练习方式 |
| --- | --- | --- |
| 农场朋友 | cow、donkey、horse、goat、cat、dog、sheep、chicken、duck、spider | 看图点读、隐藏文字找动物 |
| 观察放大镜 | big/small、long/short、new/old、old/young | 对照观察、随机换位选图 |
| 心情观察站 | happy、sad、angry、funny、beautiful、ugly；nice | 同一动物不同表情；结合情境解释词义 |
| 句子实验室 | It is…、They are…；形容词与名词；is 与 has got；isn't、aren't | 同图换句、词块选择、单复数对照 |
| 一个与一群 | It/They、is/are、a/an、规则复数与 sheep；be 否定句 | 切换数量、动物和肯否定 |
| 真假线索 | has got、hasn't got、Has it got…?；Yes, it has./No, it hasn't.；It's 的两种语境 | 换图问答、完整纠错句与缩写对照 |
| 小侦探出动 | 身体特征与颜色线索 | 同时核对两条线索猜动物 |
| 声音小线索 | 本组词中 c、k、ck 表示 /k/ | 完整单词示范、字母位置高亮、听音找图 |
| 农场带来什么 | milk、eggs、honey、wool；alpaca 与羊驼毛衣物 | 动物和产品配对、阅读点读、加工过程观察 |
| 凯西的泥巴故事 | 依照单元故事主线编写的六格短篇；心情与友善 | 分幅中英点读、连续听故事、理解选择 |
| 单词拼写屋 | 10 个动物词和 4 个产品词 | 听音看图拼写、字母计数、首字母提示 |
| 我的小农场 | Make a farm；Our farm has got… | 添加与移除动物、按数量生成完整英文句子、整句点读、打印作品 |
| 单元小挑战 | 12 题涵盖词汇、语法、拼读、产品和故事 | 记录第一次选择，给出解释与复习方向 |

动物词共 10 个，单元核心形容词与情绪词共 12 个，另复习 long/short。bee、alpaca、flies 等用于产品、阅读与故事情境，不将其混称为 10 个动物核心词的一部分。spider 是蜘蛛，不是昆虫。

## 来源与改编说明

课程范围以剑桥 Power Up Level 1 第一版学生用书教学范围（ISBN 9781108413749）和官方家长指南为依据。公开教材页预览用于核对动物词表、形容词、动物产品、羊驼及奶牛故事的教学内容。

- [剑桥官方 Level 1 教学范围](https://drupal-s3fs-prod.s3.eu-west-1.amazonaws.com/files/8815/6768/4872/Power_Up_Power_Up_L1_Scope_And_Sequence_9781108413749_Scope_and_Sequence.pdf)
- [剑桥官方家长指南](https://drupal-s3fs-prod.s3.eu-west-1.amazonaws.com/files/9815/7252/3697/Power_Up_Parents_Letters_Level_1_Power_Up_English_Home-School_Resources.pdf)
- [第三方上传的 Unit 3 教材页预览](https://www.scribd.com/document/710966515/Power-Up-1-%E5%AD%A6%E7%94%9F%E7%94%A8%E4%B9%A6-Unit-3)

本版是围绕单元学习目标制作的家庭学习工具。未取得孩子所在机构的原版 PPT、原歌曲、原动画和配套原录音，也没有逐页复刻教材。教材的 Friendly Farm 动画与歌曲任务在这里以原创听线索、描述动物等活动练习相关语言；它们不代表原节目内容。若实际使用第二版或机构重编版，应再与孩子教材对照。

奶牛故事的六幅配图与简短英文是教学改写。故事情节属于想象；泥巴只能暂时弄脏毛发，真实奶牛的毛色和花纹并非玩泥巴形成。beautiful/ugly 通过角色对作品的评价介绍，不用来给孩子或动物贴价值标签。small 描述体型，不直接等同于 young。

插图按本任务调用生图工具制作；玲娜贝儿为用户指定的陪伴角色。英式英文配音采用 Google Cloud en-GB-Neural2-A，中文采用 cmn-CN-Wavenet-A，均为语音合成，不是教材原声或真人录音。没有启用麦克风、语音识别或口语自动评分。

## 文件

index.html 为入口；assets 为插图；audio 为点读录音。audio-manifest.json 列出中英文录音文本，audio-validation.json 保存音频格式与时长检查结果。课程文本、练习和音频索引均保存在本地文件中，可继续修改扩展。
