# Unit 5：小黄鸭的生日礼物派对

完成日期：2026年11月2日。依据 Power Up Level 1 第一版（学生用书 ISBN 9781108413749），Unit 5 Happy birthday!，第56—67页。小黄鸭以用户提供的毛绒玩偶照片为视觉参考；Ben 和 Mia 是本版原创配角。网站中的图片、题目、例句及四幅故事均为原创教学改编。

## 内容与学习路线

18个核心词条：ball、bike、car、doll、house、kite、robot、plane；balloon、board game、box / toy box、computer、helicopter、keyboard、mouse、radio、ship、teddy / teddy bear。

4个形状补充词：circle、square、triangle、rectangle。house 在本单元以玩具屋呈现；mouse 指电脑鼠标，keyboard 指电脑键盘。别名共用词条。doll 的“听词”使用完整词组 a doll，页面明确标注；单词显示 doll，例句为 This is a doll.。

| 关卡 | 内容与完成条件 |
| --- | --- |
| 1 打开玩具屋 | 两组18词图卡与例句点读；完整听完18个词／词组，完成覆盖全部18词的听音选图。 |
| 2 礼物是谁的？ | 主人记录支持 Whose…? 与名字＋’s，完成6道归属题。 |
| 3 换个角度说一说 | 明确说话者、听话者和物品主人，比较 my / your / his / her / our / their，完成6道选择。our 的说话者为两位主人。 |
| 4 生日心愿侦探 | 对照 Ben、Mia 的可见心愿，练习 want / wants、doesn't want、Does…want…? 与短回答、What does…want?，完成8道题。 |
| 5 形状贺卡工坊 | 点读4种形状，选空位、贴形状，完成机器人6处拼搭。几何图形由矢量绘制，圆形和正方形保持比例。 |
| 6 小黄鸭的声音角 | 听完整 house、helicopter、happy，观察开头 h；完整听完3词记录练习完成，不自动评价发音。 |
| 7 送错礼物怎么办？ | 四幅原创故事：准备礼物、拿错、归还、道歉。逐幅或完整连播；看完4幅并完成3道理解题。 |
| 8 生日礼物派对 | 给 Ben、Mia 设定本次角色扮演心愿；从6种玩具中选符合心愿的礼物，配形状贺卡。两人都收到匹配礼物后完成，可打印作品；两人的贺卡分别保存。 |

补充练习位于派对关：原创介绍中听名字 Ben、年龄7、机器人数量2，练习名字和数量信息；另有“名字、年龄、最喜欢的玩具”三个个人问题点读，由家长听孩子回答。对应官方范围中的 Starters Listening Part 2 与 Speaking Part 4 技能，不冒充官方试题。

## 图片和声音

使用内置生图工具完成32张独立原始素材：小黄鸭标准形象1张、动作4张、Ben和Mia两张、独立玩具18张、场景3张、故事4张。原始PNG保存在本地素材目录，网页采用保留透明度的WebP。页面文字由网页排版；四种形状采用准确的SVG，不依赖生图来确定几何关系。

共159段录音，其中150段英文、9段中文；157段新完整录音、2段复用已验收的完整录音。音色 Sulafat；实际采用 gemini-2.5-flash-tts 85段、gemini-2.5-flash-lite-preview-tts 74段。逐段实际模型、语言、文本、文件名与来源记录于 audio-manifest.json。

英文采用清晰自然英式英语，适合小学听说；默认1倍，可选0.85倍。每条新录音独立完整合成，在全部录音外增加250毫秒前留白、300毫秒后留白，不切词、不按识别时间裁句、不用单词片段拼成整句。doll 改为完整词组 a doll；两条 Mia 问句使用同音发音别名 Meeya，页面与脚本仍显示 Mia。详细记录见 audio-generation.json。

159段全部通过解码、时长和首尾余量检查；独立识别156条规范化一致，3条为可明确解释的同音转写差异，未解决项0。识别相符和波形留白是质量证据，不等同于专业人工逐音素审听。
